# БронПраздник — онлайн-запись Деда Мороза

Страница записи для агентств праздников: клиент выбирает персонажей, программу, дату и время, допы и сразу видит цену. Заявки, расписание и цены агентство ведёт в админке.

- Страница агентства: `https://bronprazdnik.ru/<адрес-агентства>`
- Админка: `https://bronprazdnik.ru/admin/`
- Демо без сервера (GitHub Pages): `?a=demo`

## Первая установка на хостинг

1. Создать базу MySQL в панели хостинга.
2. На сервере в папке сайта создать `config.local.php` по образцу `config.example.php` (пароль от базы, секретная строка, ваши данные как обработчика).
3. Открыть `https://bronprazdnik.ru/install/setup.php`, придумать логин и пароль владельца.
4. Удалить папку `install` с сервера.

## Выкладка

Каждый push в `main` заливается на хостинг по FTP (GitHub Actions). Доступы хранятся в секретах репозитория: `FTP_SERVER`, `FTP_USERNAME`, `FTP_PASSWORD`, `FTP_DIR`.

## Как устроено

- `index.html`, `assets/` — страница записи. Цену показывает браузер, но окончательно считает сервер.
- `api/agency.php` — настройки агентства и занятость, `api/order.php` — приём заявки (проверка, пересчёт цены, защита от двойной брони и спама), `api/admin.php` — админка.
- `lib/booking.php` — расчёт цены и занятости.
- `admin/` — админка: заявки, расписание, цены и услуги, настройки, агентства (для владельца).
