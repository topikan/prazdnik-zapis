# Онлайн-запись Деда Мороза

Страница записи для агентств праздников: клиент выбирает персонажей, программу, дату и время, допы и сразу видит цену.

## Как подключить агентство

1. Скопировать `agencies/demo.json` в `agencies/<название>.json`.
2. Поменять название, телефон, цвета, цены, наценки по датам, количество пар артистов и часы работы.
3. Страница агентства открывается по ссылке `?a=<название>`.

Демо: `?a=demo`.
